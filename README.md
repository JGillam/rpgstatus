# wh40k-wg-assistant

WarHammer 40K Wrath and Glory Assistant — a lightweight, ephemeral "second screen" status
board for the table (Jackbox-style join), so a large group can see turn order, shared
Wrath/Glory/Ruin counters, party health, and mobs on the board without losing the plot.

📄 **Design spec:** [`docs/SPEC.md`](docs/SPEC.md) — problem, goals, AWS serverless
architecture, data model, UX (text), roadmap, and open questions. Draft for discussion.
